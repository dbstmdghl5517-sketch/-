## 체험단 견적서 자동화

Claude Code에 **"체험단 견적서"** 라고 입력하면 `.claude/agents/체험단-견적서.md` 에이전트가 동작합니다.

| 경로 | 역할 |
|---|---|
| `.claude/agents/체험단-견적서.md` | 에이전트 정의 (작성 규칙·계산 규칙·검증) |
|  `견적/1-1 체험단 견적서 양식/체험단_견적서_양식.html` | 견적서 출력 양식 HTML (`{{변수}}` 치환, 인쇄→PDF) |
| `견적/설정/공급자정보.md` | 위더스콘텐츠 사업자·계좌 정보 |
| `견적/설정/단가표.md` | 채널·옵션별 단가 마스터 |
| `견적/설정/요청양식.md` | 입력값 요청 시 되돌려줄 양식 |
| `견적/발행/{연도}/` | 생성된 견적서 저장 위치 |
| `도구/미리보기.sh` | 견적서 HTML → A4 세로 PNG·PDF 자동 생성 |
| `도구/문서변환.sh` | HTML → DOCX + PDF 변환 (Word COM, 파일명 = 업체명_항목명) |

**단가나 양식이 바뀌면 `견적/설정`·`견적/1-1 체험단 견적서 양식` 파일만 수정하면 됩니다.** 에이전트 정의는 건드릴 필요가 없습니다.
