# 체험단 견적서 – 입력 요청 양식

> 사용자가 "체험단 견적서"라고만 입력했을 때 에이전트는 이 양식을 그대로 돌려준다.
> 이미 알고 있는 값은 채워서 보여주고, 비어 있는 **필수** 항목은 `❗미입력`으로 표시한다.

아래 항목을 채워서 보내주세요. **★ 표시는 필수**입니다.
(견적일자는 오늘 날짜, 유효기간은 견적일로부터 14일, 납품기한·결제조건은 "협의"로 자동 처리됩니다.)

## 1. 수신처 (견적서 좌측 박스)
- ★ 고객사명 :
- 담 당 자 :
- 연 락 처 :
- ★ 견 적 명 :
- 참    조 :

## 2. 견적내용 (품명 표, 최대 9행) ★

| 품명 | 규격/단위 | 수량 | 단가 |
|---|---|---:|---:|
| 예) 인스타 체험단 및 블로그체험단 | 명 | 20 | 175,000 |
|  |  |  |  |

- 단가를 모르시면 비워두세요. 단가표에 있으면 자동 적용하고, 없으면 다시 여쭙겠습니다.
- 총액만 알고 계시면 "총액 OOO원 (VAT포함)" 으로 적어주셔도 됩니다.

## 3. 견적조건 (기본값과 다를 때만)
- 납품기한 : (기본 — 협의)
- 결제조건 : (기본 — 협의)
