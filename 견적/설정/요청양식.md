# 체험단 견적서 – 입력 요청 양식

> 사용자가 "체험단 견적서"라고만 입력했을 때 에이전트는 이 양식을 그대로 돌려준다.
> 이미 알고 있는 값은 채워서 보여주고, 비어 있는 **필수** 항목은 `❗미입력`으로 표시한다.
>
> ★ 묻는 방식 (2026-09-17 추가)
>   **필요한 항목을 빠짐없이 한 번에, 하나씩 번호를 붙여 묻는다.**
>   표 안에 묻어 두면 사용자가 무엇을 달라는 건지 못 알아본다.
>   특히 **품명 · 수량 · 단가 · 공급가액** 은 표 예시로 흘리지 말고 **항목으로 세워서** 묻는다.
>   질문을 여러 번 나눠 던지지 않는다. 한 번에 다 묻고 기다린다.

아래 항목을 채워서 보내주세요. **★ 표시는 필수**입니다.
(견적일자는 오늘 날짜, 유효기간은 견적일로부터 14일, 납품기한·결제조건은 "협의"로 자동 처리됩니다.)

## 꼭 필요한 것

**1. ★ 고객사명** — 견적서를 받는 회사 이름

**2. ★ 견적명** — 예) 인스타·블로그 체험단 진행 건

**3. ★ 품명** — 견적서 표에 그대로 찍히는 이름
예) `인스타 체험단 및 블로그 체험단` / `블로그 체험단 (방문형)` / `릴스 체험단`

**4. ★ 규격·단위** — `명` 또는 `건` (기본 `명`)

**5. ★ 수량** — 몇 명 / 몇 건

**6. ★ 금액** — 아래 **셋 중 하나만** 주시면 나머지는 계산합니다

| 주시는 값 | 계산되는 값 |
|---|---|
| 단가 (1명당) | 공급가액 = 단가 × 수량 → 세액 → 견적금액 |
| 공급가액 (항목 합계) | 단가 = 공급가액 ÷ 수량 → 세액 → 견적금액 |
| 총액 (VAT포함) | 공급가액 = 총액 ÷ 1.1 → 세액 → 단가 |

## 있으면 좋은 것 (없으면 비웁니다)

**7.** 담당자명   **8.** 연락처   **9.** 참조
**10.** 납품기한 (기본 — 협의)   **11.** 결제조건 (기본 — 협의)

## 한 줄로 주셔도 됩니다

```
OO주식회사 / 인스타·블로그 체험단 / 인스타 체험단 및 블로그 체험단 / 명 / 20 / 단가 175,000
```

품목이 여러 개면 줄을 나눠 주세요. **최대 9행**까지 들어갑니다.

```
블로그 체험단 (방문형) / 명 / 10 / 150,000
인스타 릴스 체험단     / 명 / 10 / 200,000
```

## 함께 안내할 것

- **지원사업 건이면 이 양식이 아니다.** 1-2 를 써야 하며 아직 미구축이다. 반드시 같이 알린다.
- `단가표.md` 가 비어 있으면 그 사실을 알리고, 이번에 받은 단가를 단가표에 넣을지 물어본다.
  넣어 두면 다음부터 업체명과 인원만으로 금액이 나온다.
