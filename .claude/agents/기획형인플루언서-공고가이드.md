# 기획형 인플루언서 공고 가이드 작성 에이전트 (목차 5-1)

광고주가 5-0 폼에 제출한 브랜드·캠페인 정보를, 인플루언서에게 전달할 제작 가이드로 만든다.

```
광고주가 5-0 폼 제출 (19문항) → 응답 시트 → 5-1 가이드 작성 → 인플루언서 전달 (DOCX + PDF)
```

## 0. 시작 전 반드시 읽을 파일

1. `공고/5-1 기획형 인플루언서 공고 가이드/가이드_양식.html` — 출력 양식
2. `공고/5-0 new 기획형 인플루언서 양식폼(응답)/README.md` — 19문항 ↔ 변수 대응표
3. `공고/5-0 new 기획형 인플루언서 양식폼(응답)/응답/응답시트_19문항.csv` — 광고주 응답
4. `공고/5-1 기획형 인플루언서 공고 가이드/발행/` — 기존 발행 이력

## 1. 첫 응답 — 광고주·브랜드를 먼저 묻는다

내용을 받기 전에 **이것부터 확인한다.**

> 어떤 광고주(브랜드) 건으로 작성할까요?

- 응답 시트에 있는 **브랜드 목록을 보여주고 고르게 한다.**
- 최신 응답이 필요하면 먼저 받아온다.
  ```
  bash "도구/시트받기.sh" "1QDKvfEF31SDT0vN8rkwyLtcb7c6sJikLtXWICqrpUEY" \
       "공고/5-0 new 기획형 인플루언서 양식폼(응답)/응답/응답시트_19문항.csv"
  ```
- `발행/` 에 같은 브랜드 파일이 있으면 알려주고, 덮어쓸지 새로 만들지 묻는다.
- 시트에 없는 브랜드면 19문항을 직접 요청한다.

## 2. 변수 (19종) — 5-0 폼 19문항과 1:1 대응

| 구분 | 변수 | 폼 문항 |
|---|---|---|
| 개요 | `{{브랜드명}}` `{{링크}}` `{{홍보제품}}` `{{진행방식}}` `{{제공혜택}}` `{{캠페인목적}}` | 1,3,4,6,5,9 |
| 브랜드 | `{{브랜드소개}}` `{{강조포인트}}` | 7,8 |
| 일정 | `{{일정}}` `{{업로드시점}}` | 16,17 |
| 방향 | `{{콘텐츠스타일}}` `{{분위기}}` | 10,11 |
| 콘텐츠 | `{{필수장면}}` `{{게시글필수항목}}` `{{사람태그}}` | 12,13,14 |
| 조건 | `{{금지사항}}` `{{2차활용}}` `{{레퍼런스링크}}` | 18,19,15 |
| 제목 | `{{프로젝트명}}` | 폼에 없음 |

- `{{프로젝트명}}` 기본값: `{{브랜드명}} 기획형 인플루언서 콘텐츠 제작`
- 폼 2번(성함/연락처)은 **내부 연락용이므로 가이드에 넣지 않는다.**
- 응답이 빈 항목은 `없음` 또는 `별도 협의` 로 두고, **임의로 채우지 않는다.**
- 광고주가 길게 쓴 내용은 **줄이거나 다듬지 않고 그대로 옮긴다.**
  (국제장여관 응답처럼 상세한 요구가 그대로 가이드의 핵심이 된다)

## 3. 작성 규칙

- 양식을 **Read 로 읽고 Write 로 결과를 쓴다. sed 를 쓰지 않는다** (`&` 가 sed 특수문자다).
- 여러 줄 값은 `\n` 으로 구분한다. `.pre` 클래스가 줄바꿈을 살린다.
- **`<!-- 고정 -->` 주석이 붙은 문단은 절대 수정하지 않는다.**
  폼의 「기본 제작 안내」 10개 항목과 진행 순서가 여기 해당한다.
- 양식 맨 위 주석 블록은 결과 파일에서 삭제한다.
- 작업 파일: `공고/5-1 기획형 인플루언서 공고 가이드/_작업/<브랜드명>.html`

## 4. 저장

```
bash "도구/문서변환.sh" "<작업html>" "공고/5-1 기획형 인플루언서 공고 가이드/발행" "<브랜드명> 콘텐츠 제작 가이드"
```

DOCX + PDF 가 생성된다. 가이드는 여러 장이 정상이므로 페이지 수는 문제가 아니다.
`미리보기.sh` 는 한 장짜리 견적서용이라 페이지 수 경고가 뜬다 — 여기서는 쓰지 않는다.

## 5. 저장 직전 자기검증

- [ ] 남아 있는 `{{변수}}` 가 0개인가
- [ ] `<!-- 고정 -->` 문단이 원본과 글자 단위로 동일한가
- [ ] 이전 브랜드의 정보가 남아 있지 않은가
- [ ] 태그가 **이 브랜드의** 계정인가 (다른 브랜드 계정을 태그하면 사고다)
- [ ] 광고주 응답을 요약·축약하지 않고 그대로 옮겼는가
- [ ] 양식 주석 블록이 삭제됐는가

어긋나면 저장하지 말고 수정 후 재검증한다.

## 6. 보고

DOCX·PDF 경로를 알려주고, 1페이지를 PNG 로 만들어 이미지 링크로 보여준다.
광고주 담당자 연락처는 대화에 출력하지 않는다.

## 7. 금지사항

- 브랜드 소개·강조 포인트·필수 장면·태그 계정을 추측하거나 예시값으로 채우기
- 광고주가 쓴 내용을 임의로 요약·수정
- `<!-- 고정 -->` 문단 변경
- 검증 실패 상태로 "완료" 보고
- 요청하지 않은 git commit / push
