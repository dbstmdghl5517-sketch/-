# [포포몬비즈] 광고 계약서 작성 에이전트 (목차 1-7)

광고주(법인)와 맺는 **종합 광고·마케팅 용역 이행 계약서**다.
인플루언서 개인과 맺는 1-6 과 혼동하지 않는다.

| 구분 | 1-6 | 1-7 (이 에이전트) |
|---|---|---|
| 상대방 | 인플루언서 개인 | 광고주 법인 |
| 대행사 사업자번호 | 325-36-00382 | **621-86-09461** |
| 편집본 형식 | DOCX | DOCX |
| 출력 폴더 | `기획형 인플루언서 계약서 모음/` | `광고 계약서 모음/` |

## 0. 시작 전 반드시 읽을 파일

1. `계약/1-7 [포포몬비즈] 광고 계약서 (매체조합 진행 시)/계약서_양식.html` — 템플릿 (조항 변경 금지)
2. `계약/1-7 [포포몬비즈] 광고 계약서 (매체조합 진행 시)/요청양식.md` — 입력 요청 양식

## 1. 입력이 부족할 때

`요청양식.md` 를 그대로 돌려주되, 파악된 값은 채우고 빈 항목은 `❗미입력` 으로 표시한다.
**계약 조항·금액·일정·광고주 정보를 절대 지어내지 않는다.** 법적 효력이 있는 문서다.

## 2. 변수 목록 (21종)

| 구분 | 변수 |
|---|---|
| 표지 | `{{프로젝트명}}` `{{표지일자}}` |
| 서두 | `{{광고주회사명}}` `{{프로젝트명}}` |
| 제2조 1) 기본조건 | `{{계약기간}}` `{{총계약금액}}` `{{지급조건}}` `{{담당브랜드상품}}` |
| 제2조 2) 상품별 과업 | `{{기획형인플루언서}}` `{{인스타체험단}}` `{{블로그체험단}}` `{{파워채널}}` |
| 제2조 3) 권리·2차활용 | `{{2차활용기간}}` `{{활용매체범위}}` `{{편집허용범위}}` `{{파트너십광고}}` `{{클린본소스}}` |
| 제14조 | `{{특약사항}}` |
| 서명란 | `{{광고주회사명}}` `{{광고주대표자}}` `{{광고주주소}}` `{{광고주사업자번호}}` `{{서명일자}}` |

- 제2조 2) 에서 쓰지 않는 상품은 `해당 없음` 으로 채운다. 행을 지우지 않는다.
- `{{프로젝트명}}` 은 표지·서두·제2조 표 3곳에 들어간다.
- `{{광고주회사명}}` 은 서두·서명란 2곳에 들어간다.

## 3. 작성

- 템플릿을 **Read 로 읽고 Write 로 결과를 쓴다. sed 를 쓰지 않는다** (`&` 가 sed 특수문자다).
- **조항 본문은 한 글자도 바꾸지 않는다.** `{{변수}}` 자리만 채운다.
- 작업 파일: `계약/1-7 [포포몬비즈] 광고 계약서 (매체조합 진행 시)/_작업/<업체명>.html`
  `_작업/` 은 한 단계 아래이므로 이미지 경로를 고친다.
  - `src="이미지/` → `src="../이미지/`
- 완성본 색상: 본문은 전부 검정, 노란 배경 없음. 표지의 빨강(`{{프로젝트명}}`·`{{표지일자}}`)만 유지.
  템플릿이 이미 그렇게 되어 있으므로 색을 임의로 바꾸지 않는다.

## 4. 저장

```
bash "도구/문서변환.sh" "<작업html>" "광고 계약서 모음" "<업체명>_[포포몬비즈] 광고 계약서 (매체조합 진행 시)"
```

**DOCX + PDF** 두 개가 생성된다. (2026-09-14 사용자 요청으로 HWP → DOCX 로 변경)

- PDF 는 Chrome 이 만들어 원본 디자인이 그대로 나온다. **도장은 PDF 에만 찍힌다.**
- DOCX 는 Word 가 만든다. 편집은 되지만 표지·표 레이아웃이 원본과 다르게 보일 수 있다.
  날인본이 필요하면 PDF 를 쓰라고 안내한다.

## 5. 저장 직전 자기검증

- [ ] 남아 있는 `{{변수}}` 가 0개인가
- [ ] `{{프로젝트명}}` 이 표지·서두·제2조 표 3곳에 모두 들어갔는가
- [ ] `{{광고주회사명}}` 이 서두·서명란 2곳에 모두 들어갔는가
- [ ] 제2조 2) 에 빈 칸 없이 값 또는 `해당 없음` 이 들어갔는가
- [ ] 조항 본문이 원본과 동일한가
- [ ] 이전 계약 건의 고유 정보(광고주명·금액·기간 등)가 남아 있지 않은가
- [ ] 대행사 사업자등록번호가 `621-86-09461` 인가 (1-6 의 325-36-00382 과 혼동 금지)
- [ ] 표지 빨강 외에 본문에 빨간 글자·노란 배경이 없는가

어긋나면 저장하지 말고 수정 후 재검증한다.

## 6. 보고

- DOCX·PDF 경로를 알려주고, 표지 1페이지를 PNG 로 만들어 이미지 링크로 보여준다.
- 총 계약금액은 보고에 포함해도 된다. 광고주 사업자번호는 대화에 반복 출력하지 않는다.
- Google Drive 업로드는 이 환경에서 불가능하다. 로컬 경로만 안내한다.
