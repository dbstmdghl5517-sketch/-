# 기획형 인플루언서 계약서 작성 에이전트 (목차 1-6)

## 0. 시작 전 반드시 읽을 파일

1. `계약/1-6 [인플루언서]기획형 인플루언서 계약서 양식/계약서_양식.html` — 템플릿 (조항 변경 금지)
2. `계약/1-6 [인플루언서]기획형 인플루언서 계약서 양식/요청양식.md` — 입력 요청 양식

원본 구글 문서는 `원본_구글문서.html` 에 보관돼 있다. 대조가 필요할 때만 읽는다.

## 1. 입력이 부족할 때

`요청양식.md` 를 그대로 돌려주되, 파악된 값은 채우고 빈 항목은 `❗미입력` 으로 표시한다.
**계약 조항·금액·날짜·개인정보를 절대 지어내지 않는다.** 법적 효력이 있는 문서다.

## 3. 작성

- 템플릿을 **Read 로 읽고 Write 로 결과를 쓴다. sed 를 쓰지 않는다**
  (`&` 가 sed 특수문자라 `&nbsp;` 등이 깨진다).
- **조항 본문은 한 글자도 바꾸지 않는다.** `{{변수}}` 자리만 채운다.
- 작업 파일은 `계약/1-6 [인플루언서]기획형 인플루언서 계약서 양식/_작업/<업체명>.html` 로 쓴다.
  `_작업/` 는 한 단계 아래이므로 이미지 경로를 **두 군데 모두** 고쳐야 한다.
  - `src="이미지/` → `src="../이미지/`  (도장 이미지)
  - `url("이미지/` → `url("../이미지/`  (표지 배경 — CSS background-image. 빠뜨리기 쉽다)

## 4. 저장

```
bash "도구/문서변환.sh" "<작업html>" "기획형 인플루언서 계약서 모음" "기획형 인플루언서 [업체명] 계약서"
```

DOCX·PDF 두 개가 생성된다. PDF 는 Chrome 이 만들어 원본 디자인이 그대로 나오고,
DOCX 는 Word 가 만들어 편집은 되지만 표지 배경이 다르게 보일 수 있다.

## 5. 저장 직전 자기검증

- [ ] 남아 있는 `{{변수}}` 가 0개인가
- [ ] 표지 프로젝트명·일자가 채워졌는가
- [ ] 인플루언서 성함이 서두·서명란·동의인란 **3곳 모두**에 들어갔는가
- [ ] 인플루언서 서명란이 7줄(성함·연락처·플랫폼·계정ID·은행명·계좌번호·주민번호)인가
- [ ] 조항 본문이 원본과 동일한가 (`원본_구글문서.html` 과 대조)
- [ ] 이전 계약 건의 고유 정보(광고주명·장소·혜택 등)가 남아 있지 않은가
- [ ] 주민번호·계좌번호가 사용자가 준 값과 정확히 일치하는가
- [ ] 표지 배경(`url(../이미지/img1.png)`)이 실제로 보이는가 — 렌더링해서 눈으로 확인.
      PDF 용량이 100KB 미만이면 배경이 빠진 것이다

어긋나면 저장하지 말고 수정 후 재검증한다.

## 6. 보고

- DOCX·PDF 경로를 알려주고, 표지 1페이지를 PNG 로 만들어 이미지 링크로 보여준다.
- **주민번호·계좌번호는 대화에 다시 출력하지 않는다.** "입력값대로 반영함" 으로만 보고한다.

## 7. 금지사항

- 계약 조항 문구 변경·추가·삭제
- 개인정보(주민번호·계좌번호·성함) 추측하거나 예시값으로 채우기
- 검증 실패 상태로 "완료" 보고
- 계약서 산출물을 git 에 커밋 (개인정보 포함, `.gitignore` 로 제외돼 있음)
- 요청하지 않은 git commit / push
