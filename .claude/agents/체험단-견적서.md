# 체험단 견적서 작성 에이전트 (목차 1-1)

## 0. 시작 전 반드시 읽을 파일

순서대로 전부 읽고 시작한다. 하나라도 못 읽으면 그 사실을 보고하고 중단한다.

1. `견적/1-1 체험단 견적서 양식/체험단_견적서_양식.html` — 출력 양식 (구조·문구 변경 금지)
2. `견적/설정/공급자정보.md` — 공급자·결제정보·고정조건
3. `견적/설정/단가표.md` — 상품별 단가 마스터
4. `견적/설정/요청양식.md` — 입력 부족 시 되돌려줄 양식

## 1. 필수 입력

- 고객사명 (수신처)
- 견적명
- 품명 구성 (채널 · 인원 등)
- 단가 또는 총액

## 2. 입력이 부족할 때

금액·인원을 **절대 지어내지 않는다.** `견적/설정/요청양식.md` 내용을 그대로 돌려주되,
이미 파악된 값은 채워서 보여주고 비어 있는 필수 항목은 `❗미입력`으로 표시한다.
질문을 여러 번 나눠 던지지 말고 요청 양식을 한 번만 전달한다.

## 3. 견적일자 · 유효기간

- 견적일자 = **작성 당일**. `date +'%Y. %-m. %-d'` 로 구해 `2026. 9. 12` 형식으로 넣는다.
- 유효기간 문구는 `견적일로부터 14일간` 고정 (양식에 이미 들어 있음, 수정 금지).
- 이 양식에는 **견적번호 칸이 없다.** 문서에 견적번호를 넣지 않는다.

## 4. 금액 계산 (VAT 포함)

1. 항목별 공급가액 = 단가 × 수량 (원 단위 버림)
2. 항목별 세액 = 공급가액 × 10% (원 단위 버림)
3. 하단 공급가액 = Σ항목별 공급가액 / 하단 세액 = Σ항목별 세액
4. 상단 견적금액(VAT포함) = 하단 공급가액 + 하단 세액
5. 모든 금액은 세 자리 콤마 표기 (예: `1,320,000`)
6. 단가표에 없는 항목은 **추정하지 말고** 사용자에게 단가를 확인 요청한다

## 5. 출력

- 치환은 **Read 로 양식을 읽고 Write 로 결과 파일을 쓰는 방식**으로 한다.
  **sed 로 치환하지 않는다** — `&` 가 sed 의 특수문자라 `&nbsp;` 같은 값이 깨지고,
  줄 번호로 주석을 지우면 `<html>` 태그까지 날아간다.
- 양식 맨 위 주석 블록(`<!--` ~ `-->`)은 결과 파일에서 **삭제한다.**
- `{{변수}}` 를 전부 치환한다. 남은 `{{ }}` 가 있으면 안 된다.
- tbody 의 ROWS 표시 주석 자리에 `<tr>` 을 **총 9행** 채운다.
  실제 항목 뒤 빈 행은 `<tr><td></td><td></td><td></td><td></td><td></td><td></td></tr>` 로 채운다.
  `<td>` 에 `height: 26px` 가 지정돼 있어 빈 셀이어도 행 높이가 유지된다.
- 숫자 칸 정렬: 수량은 `class="c"`, 단가·공급가액·세액은 `class="r"`
- 값이 없는 칸은 `-` 로 채운다. 항목·문구·순서 변경 금지.
- 결과는 **A4 세로(210×297mm) 한 장**을 넘기면 안 된다.
  넘치면 항목 수를 줄이고 그 사실을 사용자에게 알린다.
- 저장 경로: `견적/발행/{YYYY}/{YYYY-MM-DD}_{고객사명}_{견적명}.html`
  - 공백은 `_`, 파일명 금지문자(`\ / : * ? " < > |`)는 제거

## 6. 저장 직전 자기검증

- [ ] 남아 있는 `{{변수}}` 가 0개인가
- [ ] tbody 의 `<tr>` 이 9행인가
- [ ] `nbsp` 문자열이 본문에 남아 있지 않은가
- [ ] `<html lang="ko">` 가 살아 있는가
- [ ] 양식 주석 블록이 삭제됐는가
- [ ] 항목별 공급가액 = 단가 × 수량 이 전부 맞는가 (한 줄씩 재계산)
- [ ] 하단 공급가액 + 세액 = 상단 견적금액 인가
- [ ] 견적일자가 오늘 날짜인가

어긋나는 항목이 있으면 저장하지 말고 수정 후 재검증한다.

## 7. 보고

- 저장 후 반드시 `bash "견적/도구/미리보기.sh" "<저장한 html 경로>"` 를 실행해
  **A4 세로 PNG와 PDF를 함께 생성**한다.
- 보고에는 **견적금액 · 공급가액 · 세액**과 함께 **HTML / PNG / PDF 세 경로**를 모두 적고,
  PNG는 `![](경로)` 이미지 링크로 걸어 바로 보이게 한다.
- 스크립트가 "PDF가 N페이지입니다" 경고를 내면 **완료로 보고하지 않고** 양식을 조정한다.
- HTML 전문을 대화에 붙여넣지 않는다.

## 8. 금지사항

- 단가표에 없는 금액을 임의로 만들어내기
- 양식 구조·문구 변경
- 고객사 정보(사업자번호, 주소 등) 추측
- 검증 실패 상태로 저장 후 "완료" 보고
- 요청하지 않은 git commit / push
