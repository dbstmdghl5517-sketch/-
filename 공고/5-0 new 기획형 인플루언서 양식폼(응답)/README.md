# 5-0 new 기획형 인플루언서 양식폼 (응답)

광고주가 기획형 인플루언서 모집 시 **브랜드·캠페인 정보를 제출하는 폼**과 그 응답 시트.
**이미 운영 중인 폼이며, 여기 있는 항목만 사용한다.** 새로 항목을 만들지 않는다.

이 응답을 받아 **5-1 기획형 인플루언서 공고 가이드**를 작성한다.

```
광고주가 폼 제출  →  응답 시트  →  5-1 가이드 작성  →  인플루언서 전달
```

사용자가 다른 이름을 주면 그걸 따른다.

## 폼의 「기본 제작 안내」 — 가이드 고정 문구

폼 하단 안내문이며 **모든 캠페인에 공통 적용**된다. 5-1 양식에 이미 고정 문구로 들어가 있다.

- 인스타그램 릴스는 9:16 세로형으로 제작합니다.
- 영상 시작 1~3초 내 시선을 끌 수 있는 장면 또는 후킹 요소를 권장합니다.
- 과도한 광고 문구보다는 실제로 제품이나 서비스를 체험한 후기처럼 자연스럽게 표현합니다.
- 제품 또는 서비스를 실제로 사용하는 장면이 포함될 수 있도록 제작합니다.
- 자막 및 나레이션을 활용하여 콘텐츠 내용이 자연스럽게 전달될 수 있도록 제작합니다.
- 업로드 전 완성된 콘텐츠 및 게시글 초안 제출을 기본으로 합니다.
- 담당자 확인 후 최종 업로드를 진행합니다.
- 사용 음원은 인스타그램 제공 음원 또는 저작권 문제가 없는 음원을 사용합니다.
- 촬영 시 저작권 및 초상권 문제가 발생하지 않도록 유의합니다.
- 경쟁 브랜드가 콘텐츠에 노출되지 않도록 유의합니다.

## 16문항 시트를 쓸 경우

컬럼 이름이 다르다. `브랜드명 / 성함 / 연락처` 가 한 칸에 합쳐져 있고,
`이번 미션 핵심` `콘텐츠 방향` `콘텐츠 필수 포인트` `영상 길이` `콘텐츠 제출일`
`인사이트 제출 기한` `장소 태그 · 필수 해시태그` 항목이 별도로 있다.
19문항 시트와 항목이 1:1로 맞지 않으므로, 이 시트를 쓸 때는 어떤 값을 어디에 넣을지 확인한다.
