# 3-0 체험단 공고 양식폼

기업이 체험단을 요청할 때 작성하는 신청서다. 3-1(기업 확인용 가이드)과 4(모집용 공고)의 입력이 된다.

```
기업이 3-0 제출 → 3-1 가이드 작성 → 기업 확인 → 4 모집 공고 → 참여자 모집
```

기획형 인플루언서의 `5-0 → 5-1 → 6` 과 같은 흐름이다.

## 운영 중인 폼이 두 개다

| | 시트명 | 문항 | 특징 |
|---|---|---|---|
| **A** | `1.체험단 양식폼 요청서` | 12 | 항목이 하나씩 나뉘어 있다 |
| **B** | `new체험단 브랜드 정보 양식폼 (응답)` | 8 | 한 문항에 여러 정보를 묶어 받는다 |

둘 다 쓴다. 어느 폼으로 들어왔는지에 따라 읽는 방법이 다르다.

## 응답 받아오기

두 시트 모두 **비공개**다. 계약·연락처가 들어 있어 링크 공개를 닫았다.
그래서 CSV 내보내기(`도구/시트받기.sh`)로는 못 읽는다. 웹앱 경유로 읽는다.

```
bash "도구/시트보기.sh" 1RFzR8NJ6a2GeYsRiu7AVOm7nVdPL2Xx-J74BFt7K5ug     # A
bash "도구/시트보기.sh" 1ijErOco1VbWAdgBFFpWiyePbeW9720SIkVip4Q4P3e8     # B
```

## A폼 — 12문항 ↔ 변수

| 열 | 문항 | 변수 |
|---|---|---|
| 0 | 타임스탬프 | `접수일` |
| 1 | 브랜드 명 또는 매장 명 | `브랜드명` |
| 2 | 성함 / 연락처 | `담당자` |
| 3 | 체험단 요청 인원 | `모집인원` |
| 4 | 캠페인 형태 | `캠페인형태` |
| 5 | 제작 콘텐츠 형태 | `콘텐츠형태` |
| 6 | 최대 모집 기간 | `모집마감` |
| 7 | 방문 또는 체험 가능 기간 | `체험기간` |
| 8 | 방문 및 체험 가능 시간 | `체험시간` |
| 9 | 제공 상품 및 가격 | `제공내역` |
| 10 | 반드시 소개해야 하는 핵심 내용 | `핵심내용` |
| 11 | 반드시 촬영해야 하는 장면 | `필수장면` |
| 12 | 브랜드 공식 인스타그램 계정 | `사람태그` |

A폼에 **없는 항목**: `방문주소`, `추가전달`

## B폼 — 8문항 ↔ 변수

한 문항에 여러 정보가 들어온다. 값을 나눠 읽어야 한다.

| 열 | 문항 | 변수 |
|---|---|---|
| 0 | 타임스탬프 | `접수일` |
| 1 | 브랜드명과 담당자 정보 | `브랜드명` + `담당자` ← 한 칸에 섞여 있다 |
| 2 | 체험단 정보 (모집인원, 진행채널) | `모집인원` + `콘텐츠형태` ← 한 칸 |
| 3 | 체험 가능 기간 및 방문주소 | `체험기간` + `방문주소` ← 한 칸 |
| 4 | 제공되는 내용 (상품·판매가·원고료) | `제공내역` |
| 5 | 홍보하고 싶은 내용 · 강조 포인트 | `핵심내용` |
| 6 | 반드시 포함할 촬영 장면 | `필수장면` |
| 7 | 태그할 공식 인스타그램 계정 | `사람태그` |
| 8 | 추가로 전달할 내용 | `추가전달` |

B폼에 **없는 항목**: `캠페인형태`(2번에서 유추), `모집마감`, `체험시간`

## 한 칸에 섞인 값 다루기

**기계가 정확히 나눌 수 없다.** 기업이 자유롭게 쓰기 때문이다.

- `홍길동/01000000000` — 슬래시로 나뉘기도 하고
- `홍길동 대표 / 010-0000-0000 / 현장은 김실장 010-0000-0000` — 셋이 들어오기도 한다

(실제 응답을 예시로 적지 않는다. 담당자 연락처가 저장소에 남는다)

그래서 **나누는 일은 사람이 확인한다.** 3-1 작성 시 원문을 그대로 읽고 판단한다.
정규식으로 무리하게 쪼개면 담당자 이름에 전화번호가 붙거나 주소가 잘린다.

## 기업이 비워 낼 때가 많은 항목

체험단도 기획형과 같다. 기업은 참여자에게 무엇을 요청해야 할지 모르는 경우가 많다.
아래는 3-1 에서 **포포몬비즈가 조사해 채운다.**

| 항목 | 비었을 때 |
|---|---|
| `핵심내용` | 업체를 조사해 강조 포인트를 만든다 |
| `필수장면` | 업종·공간에 맞는 촬영 장면을 제안한다 |
| `게시글필수항목` | 폼에 문항이 없다. 항상 포포몬비즈가 만든다 |
| `필수해시태그` | 폼에 문항이 없다. 브랜드명·지역·업종에서 끌어낸다 |
| `금지사항` | 폼에 문항이 없다. 공통 주의사항을 넣는다 |

`없음` 으로 적혀 와도 그대로 내보내지 않는다. 참여자에게 줄 기준이 없기 때문이다.

## 담당자 연락처 취급

두 폼 모두 담당자 성함·휴대전화가 들어 있다.

- 응답 사본을 `응답/` 에 내려받으면 **커밋하지 않는다** (`.gitignore` 로 제외돼 있다)
- 대화에 연락처를 출력하지 않는다
- 3-1·4 산출물에 담당자 연락처를 넣지 않는다. 참여자가 보는 문서다
