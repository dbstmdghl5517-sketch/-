# 6-1 공동구매 공고

「공동구매 캠페인 요청서」(구글폼 18문항)가 제출되면 **사람 손을 거치지 않고** 바로 나간다.

```
업체가 요청서 제출 → 통합시트 응답 탭 → 가이드(구글 문서) + 노션 공고(인스타·릴스) + 이력 + 알림 메일
```

- 폼: https://docs.google.com/forms/d/e/1FAIpQLSc7CFVERv3dqm9-tDKeJpg9M3Q9oBffUZD_Z8ryZkj7rDGO_A/viewform
- 코드: [연동/공동구매.gs](../../연동/공동구매.gs) — 설정·문구는 전부 파일 맨 위에 있다
- 노션: `체험단 공고 가이드` › `🛒 공동구매 공고` (40721cbd…2162e)
- 드라이브: `공동구매 공고 가이드` 폴더
- 이력: 통합시트 `가이드·공고 이력` 탭, 종류 `공동구매`, 채널 `피드`(인스타)·`릴스`

## 체험단(3-1·4)과 다른 점

| | 체험단 | 공동구매 |
|---|---|---|
| 만드는 사람 | 클로드가 조사해 보완 | Apps Script 가 폼 값 그대로 |
| 채널 | 매번 물어봄 | 인스타·릴스 고정 (블로그 없음) |
| 비운 칸 | 조사해 채움 | 공통 문구로 채우고 가이드에 빨강 표시 |

## 공고에 넣지 않는 것

담당자 연락처 · 희망 인원(10) · 제공 수량/재고(12) · 기타 요청(18).
18번은 업체가 포포몬비즈에게 하는 말이 섞일 수 있어 **가이드에만** 싣는다.

## 언제 도는가

- 폼 제출 트리거 `공구_새응답처리` (편집기에서 `공구_트리거설치` 를 한 번 실행해야 생김)
- 10분 주기 `놓친행확인` 안에서도 함께 돈다 — 트리거가 없어도 10분 안에 처리된다
- 응답 탭은 이름이 아니라 머리글(「공동구매 진행 상품명」)로 찾는다

## 다시 만들기

편집기에서 `공구_다시만들기` 안의 브랜드명을 고쳐 실행한다. 같은 업체·채널의 옛 노션 공고는 보관되고 문서는 휴지통으로 간다.
