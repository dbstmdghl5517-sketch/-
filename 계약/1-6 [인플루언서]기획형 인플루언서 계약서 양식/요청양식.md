# 1-6 [인플루언서]기획형 인플루언서 계약서 – 입력 요청 양식

> 사용자가 "1-6" 또는 "[인플루언서]기획형 인플루언서 계약서 양식" 이라고 하면
> 이 양식을 그대로 돌려준다. 비어 있는 항목은 `❗미입력` 으로 표시한다.

원본 양식에서 **빨간색으로 표시된 부분**이 계약 건마다 바꿔야 하는 내용입니다.
아래를 채워서 보내주세요.

## A. 표지 (빨간색)
- 프로젝트명 :            ← 표지 `<   >` 안에 들어갑니다
- 표지 일자 :             ← 예) 2026. 04. 29.

## B. 계약 당사자
- 광고주명 (빨간색) :     ← 예) 아쿠아필드 하남점. 본문 9곳에 자동 반영됩니다

## C. 기간·장소 (빨간색 포함)
- 계약기간 :              ← 예) 2026년 4월 29일 ~ 2027년 4월 28일
- 방문 장소 (빨간색) :    ← 예) 경기 하남시 신장동 616 3층
- 방문 일자 :             ← 예) 2026년 5월 1일(금)~ 5월 10일(일) 내 사전 제출한 방문 일자
- 업로드 기한 (빨간색) :  ← 예) ~2026년 5월 14일(목)까지
- 게시물 유지기간 :       ← 예) 90일
- 계약 체결일 (빨간색) :  ← 예) 2026년 4월 29일
- 개인정보 동의서 일자 :  ← 예) 2026년 4월 29일

## D. 대가
- 원고료 :                ← 예) 원고료 30만원(원천세 제외 후 지급)
- 제공 혜택 :             ← 예) 워터파크 이용권+식음 1종. 제품·서비스 제공분

## E. 인플루언서 정보 (서명란 7줄)
- 성함 :                  ← 서두 · 서명란 · 동의인란 3곳에 함께 들어감
- 연락처 :
- 플랫폼 :               ← 예) 인스타그램 / 유튜브 / 틱톡
- 계정 ID :              ← 예) @hong_daily
- 은행명 :
- 계좌번호 :
- 주민번호 :

## F. 저장 정보
- 업체명 :                ← 파일명 `기획형 인플루언서 [업체명] 계약서` 에 들어갑니다
