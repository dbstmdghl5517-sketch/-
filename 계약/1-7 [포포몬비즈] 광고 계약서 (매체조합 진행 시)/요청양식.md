## A. 표지
- 프로젝트명 :            ← 표지 `< >` 안 + 본문 서두 + 제2조 표에 함께 들어감
- 표지 일자 :             ← 예) 2026년 9월 14일

## B. 계약 기본 조건 (제2조 1)
- 계약 기간 :             ← 예) 2026년 9월 14일 ~ 2027년 9월 13일
- 총 계약금액 :           ← 예) 총 10,000,000원 / VAT 별도
- 지급 조건 :             ← 예) 계약금 50% / 잔금 50%
- 담당 브랜드·상품 :      ← 예) ○○브랜드 / ○○ 제품

## C. 상품별 세부 과업 (제2조 2)
사용하지 않는 항목은 `해당 없음` 이라고 적어주세요.
- 기획형 인플루언서 :     ← 예) 인스타 릴스 5명 / 방문형 / 1인 원고료 30만원 포함 / 초안 검수 1회 / 업로드 10월 내 / 게시물 90일 유지
- 인스타 체험단 :         ← 예) 릴스 20명 / 제품 제공 / 모집·선정·업로드 확인 / 업로드 기간 10.01~10.31 / 게시물 90일 유지
- 블로그 체험단·기자단·키워드 시딩 : ← 예) 네이버 블로그 체험단 20명 / 메인 키워드 ○○ / 방문형 / 업로드 기간 / 게시물 90일 유지
- 파워채널·제휴채널 :     ← 예) 여행다녀왔습니다 2건 + 1일1핫플 1건 / 릴스 또는 피드 / 업로드 희망일 / 게시 유지기간

## D. 콘텐츠 권리·2차 활용 (제2조 3, 기획형 인플루언서만 해당)
- 2차 활용 / 저작권 기간 : ← 예) 6개월 (미사용이면 `미사용`)
- 활용 매체·범위 :        ← 예) 광고주 공식 SNS, 홈페이지, 쇼핑몰 상세페이지, 디지털 광고 소재, 오프라인 제작물
- 편집 허용 범위 :        ← 예) 비율·사이즈 조정, 자막·로고 삽입 허용 / 내용·취지 변경 편집 불가
- 파트너십 광고 :         ← `미진행` 또는 `진행, 권한 제공기간 ○일`
- 클린본 소스 :           ← `미제공` 또는 `제공`
